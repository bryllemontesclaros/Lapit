# Lapit Brand Direction

## Style

Lapit uses a playful Filipino transit neo-brutalist style: bold black outlines, cream paper backgrounds, hard sticker-like shadows, rounded poster typography, and strong transit colors.

The goal is to feel local, confident, and easy to understand. The brand can be loud on the landing page, but the map must stay clear and useful.

## Visual Principles

- Use cream, black, yellow, red, blue, and green as the core palette.
- Use thick borders and hard shadows for landing cards, buttons, callouts, and onboarding.
- Keep map controls simpler than landing sections so the app still feels like a real utility.
- Use short, direct copy: “Ride like you live here”, “Find the sakayan”, “Add local spots”.
- Avoid decorative clutter on the active map. Pins, labels, routes, and actions must remain the main focus.

## Applied Phases

### Phase 1: Brand Direction

The app now has a clear visual language inspired by playful editorial travel sites, adjusted for a transit product.

### Phase 2: Landing Overlay

The guest/sign-in overlay now acts as the landing page, with a ticker, bold headline, feature cards, coverage stats, and stronger call-to-action buttons.

### Phase 3: App Shell Restyle

The map brand, action buttons, account controls, panel cards, filters, route card, and legend now share the same visual direction while preserving map readability.

### Phase 4: Mobile UX Polish

The mobile map now uses tighter top controls, a cleaner action row above the bottom sheet, safer iOS viewport spacing, compact map branding, stronger tap targets, and a less crowded legend.

### Phase 5: QA and Production Cleanup

The app now includes cache-bumped CSS, viewport safe-area support, reduced-motion handling, and documented rules for keeping the landing page expressive while keeping the map usable.

## What Should Stay Clean

- Pin placement and labels
- Route line visibility
- Location and add-pin flows
- Account/auth dialogs
- Mobile map viewport

These are product workflows, so they should not become overly decorative.
